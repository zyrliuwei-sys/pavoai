## Two separate ways to create

Pavo AI offers text-to-image with **Nano Banana 2** and **Seedream 4**, and text-to-video with **Seedance 2.0** and **Wan 2.7**. Both start with a written prompt. There is no image-upload or image-to-video input in the current generator.

## Explore a still image

Choose Image, select a model and set the aspect ratio and quality. Try:

> A sage green ceramic cup on warm limestone, soft window light from the left, a fixed medium shot and a clean background.

## Plan a video separately

Use the same description as a starting point in Video, then add one movement:

> A sage green ceramic cup on warm limestone. A thin curl of steam rises slowly, soft window light from the left, fixed camera.

These are separate generations. The video does not use the generated image as an input, and matching the exact subject is not guaranteed.

## Review and save

Review the displayed credit cost before each request. Registered results appear in [My Creations](/settings/works). Guests can receive a download link by email; without an email, download before refreshing.
