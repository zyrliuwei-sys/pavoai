## Make a first test in the workspace you chose

On pavo-ai.work, open the creation screen and look at the selected workflow and model before you submit. For a first motion test, try one simple action: “A folded paper lantern hangs from a thin cord. It sways slightly to the right, then settles. The camera stays fixed and the entire lantern remains in frame.” If you use a reference, start with one image and check that it is attached to the prompt.

On pavoai.net, the same description can be pasted into [Video mode](/?mode=video#generator). Choose the aspect ratio and resolution for your intended output, then review the displayed credit cost. If you want to design the lantern still first, use [Image mode](/?mode=image#generator) and save its prompt for the video pass.

## Choose a starting point on pavo-ai.work

For one clip or still, start from the creation screen and decide whether the prompt needs a reference. A sentence is enough for a simple scene. If the position or appearance of a subject matters, attach a still and explain what the result should preserve. The workspace's public prompt box shows an example of referring to attached material with an `@` mention. With multiple references, state which one provides the appearance and which one provides the movement.

Short Drama and Infinite Canvas appear as separate entry points on [pavo-ai.work](https://pavo-ai.work/). For a story, outline the scene in one or two sentences before choosing a workflow. If you already have several visual ideas, keep your references together and give each a clear purpose. Test a single shot first so you have a working prompt and a visual direction for the rest of the project.

## If the browser opens but you can't find your project

1. Compare the address bar with the bookmark, receipt or tab where you first used the workspace. Start there if the two addresses differ.
2. Check which account and sign-in method you used before. A blank history on a different account tells you little about the original project.
3. Look for the generation status before trying the same request again. Keep a local copy of your prompt and any source images so you can reproduce the test.
4. If you need help with a charge, gather the date, order reference and the name of the site or app shown on your receipt. Use the support channel for that service.
